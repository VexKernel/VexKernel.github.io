2.Linux函数调用约定

2026/11/8 pwn学习笔记 Linux

Linux函数调用约定

调试测试

  • 通过分别编译一份X86/X64的C语言源码后传到本机用IDA来看函数调用,Linux的类Windows .EXE文件的格式为.ELF.
  • 编译X86指令:

    C++:sudo g++ -m32 XXXX.cpp -o XXXX.elf
    C:sudo gcc -m32 XXXX.c -o XXXX.elf

  • 编译X64指令:

    C++:sudo g++ -m64 XXXX.cpp -o XXXX.elf
    C:sudo gcc -m64 XXXX.c -o XXXX.elf

#include <stdio.h>
#include <unistd.h>

int Add(int a, int b, int c, int d, int e, int f, int g) {
    return a + b + c + d + e + f + g;
}

int main() {
    int sum = Add(1, 2, 3, 4, 5, 6, 7);
    printf("sum: %d \r\n", sum);
    return 0;
}

X86调用约定

  • 全部通过栈传递,由调用者平衡栈.

X64调用约定

  • 前6个参数通过RDI,RSI,RDX,RCX,R8,R9传参,其余通过栈传参,由调用者平衡栈.

总结

  • Linux X86和X64各有一套最常用的默认用户态函数ABI,即上面记录的.
