1.Linux栈

2026/11/6 pwn学习笔记 Linux

与Windows差异

  • 由于笔者本身是有较深Windows逆向基础的,所以很多东西都会和Windows进行差异化记录/对比来方便自己理解.
  • Linux栈和Windows栈一样,都是用E/RSP为栈顶,E/RBP为栈底,操作指令也都是PUSH/POP/CALL/RET.
  • 笔者自己总忘这里标粗记一下,PUSH/POP/CALL/RET操作的是E/RSP

PUSH

  • 为了方便初学者记忆,这里写下可替代的”初等汇编指令”(这里名取自复合函数和拆分后的初等函数,学高数有点魔了).
// push XXX 等价于
__asm {
    sub E/RSP, 0x4/0x8
    mov [E/RSP], XXX
}
  • 这里的0x4/0x8不是取决于XXX的数据长度,而是平台位数.运行线程是X64时,0x8;运行线程是X86时,0x4.

POP

// pop XXX 等价于
__asm {
    mov XXX, [E/RSP]
    add E/RSP, 0x4/0x8
}

CALL

// call XXX 等价于
__asm {
    push E/RIP
    jmp XXX
}

RET

// ret 等价于
__asm {
    pop E/RIP
}
